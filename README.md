# Waste Classification Using CNN and MobileNetV2

## 📌 Project Overview

This project focuses on classifying waste images into different categories using deep learning techniques.

Two approaches were implemented and compared:

* Convolutional Neural Network (CNN)
* MobileNetV2

The project was developed and trained using Google Colab.

## 🛠️ Technologies Used

* Python
* TensorFlow / Keras
* Google Colab
* CNN
* MobileNetV2
* NumPy
* Matplotlib

## 🔄 Project Workflow

1. Load the waste image dataset
2. Preprocess and resize the images
3. Split the dataset into training and validation data
4. Build a CNN model
5. Train and evaluate the CNN model
6. Build a MobileNetV2-based model
7. Train and evaluate the MobileNetV2 model
8. Compare the model performance
9. Test the model with sample waste images

## 🧠 Models Used

### CNN

A Convolutional Neural Network was implemented as a baseline deep learning model for waste image classification.

### MobileNetV2

MobileNetV2 was used as a transfer-learning-based model to improve image classification performance while keeping the model lightweight.

## 📊 Results

The models were evaluated using training and validation accuracy.

The MobileNetV2 model achieved better validation performance than the baseline CNN in the experiments.
